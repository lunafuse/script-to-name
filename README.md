# ネームプロト

台本を書くと、漫画のネーム（コマ割りと吹き出し）を即時に並べて見せるプロトタイプ。HTML 1枚で動く。

https://lunafuse.github.io/nems-proto/

- 作品は手元の `.json` ファイルにだけ保存する。サーバーには何も送らない。
- 同じファイルへの上書き保存は Chrome / Edge で動く。ほかのブラウザではダウンロード保存になる。
- 「サンプル」ボタンで、記法の見本の台本を開ける。
